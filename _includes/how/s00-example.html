The example

One search term, three repositories.

Everything below runs on the small system that ships with panopticode's frontends: a SvelteKit web app (a page in the browser, and its server, a backend-for-frontend or BFF), a GraphQL gateway in Go, and a gRPC service in Go with a SQL store. We follow one value: the search term a user puts in the page's URL, all the way to a SQL query two services away.
