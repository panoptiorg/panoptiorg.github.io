Give both ends of a network call one name

The two ends of a network call live in different repositories, read by separate runs of a frontend that never see each other. But both ends are built from the same schema, so each side can work out the same name on its own: the type or service and the field or method. Each side hashes its name into an id, and the engine links equal ids.
