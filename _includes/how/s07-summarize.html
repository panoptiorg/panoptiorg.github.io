07 · engine

Summarize every function, callees first

For every function, the engine writes a summary: if untrusted data comes in here, it goes out there, or it reaches this sink. A caller does not read a callee's map; it reads the callee's summary. So callees come first: the engine orders the functions so that each one is summarized after everything it calls.

Functions that call each other in a circle have no first one. The engine finds such groups and summarizes their functions together, round after round, until no summary changes.
